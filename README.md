# AMIS QR 일괄저장

검사의뢰서의 QR코드(예: `26-C -053637`)를 연속으로 태그해서 목록을 만든 뒤,
AMIS **병리결과입력** 화면에서 검사번호를 하나씩 조회하고 **기본값 그대로 F9(저장)** 하는 자동화 프로그램입니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| QR 태그 목록 | QR 스캐너로 태그하면 목록에 바로 추가 (중복 자동 차단, 한글 상태로 스캔된 `ㅊ` → `C` 자동 보정) |
| 자동 저장 | AMIS 검사번호 칸(노란 칸) 클릭 → 번호 입력 → 조회 확인 → **F9 저장** |
| 사용자 우선 | AMIS나 다른 프로그램을 쓰는 동안(키보드/마우스 입력)은 자동으로 멈추고, **설정한 시간(기본 5초)** 동안 입력이 없으면 이어서 진행 |
| 상태 표시 | 목록 옆에 `● 저장완료` / `○ 대기중` / `▶ 진행중` / `✕ 저장실패` 색상 표시, 실패 사유 기록 |
| 진행률 | 작업 % 바 + 전체/저장완료/대기중/저장실패 건수 |
| 작업 화면 | 오른쪽 패널에 AMIS 화면 실시간 미리보기 (빨간 원 = 입력 위치) |
| 축소창 | 항상 위에 떠 있는 작은 창으로 현재 검사번호·AMIS 화면·진행률 확인 |
| 기록 | 목록은 `qr_list.json` 에 자동 저장(재실행해도 유지), 작업 로그는 `logs/날짜.log` |

## 검사코드 QR (v2.4.0)

새 검사의뢰서 QR 은 `26C 054730;A;1;;FB0164;1` 형식입니다.

- `26C 054730` → **검사번호**. 예전 QR 과 같은 모양 `26-C -054730` 으로 바꿔서 처리하므로 병리결과입력에 번호를 넣는 방식은 예전과 똑같습니다
- `A;1;` 등 나머지 칸은 무시
- `FB0164` → **검사코드**. `검사코드.xlsx`(A열 처방코드, B열 처방영문명)에서 찾아 목록 **검사명** 컬럼에 표시
  (엑셀이 없으면 프로그램 안의 내장 표 사용, 설정 ▸ *검사코드표 엑셀* 에서 파일 지정 / 다시 불러오기)
- 한글 상태로 스캔된 `26ㅊ 054730;ㅁ;1;;류0164;1` 도 자동 보정됩니다.

검체 종류에 맞는 체크 칸만 켜지고, 나머지는 `－` 로 비활성화됩니다(눌러도 체크되지 않고 저장 시에도 무시).

| 체크 칸 | 활성화되는 검체 (검사명에 포함된 글자) |
|---|---|
| Urine <30ml, UC absent | urine, bladder irrigation |
| Inst 10~20, Inst <10 | bladder irrigation, washed urine (Instrumented urine) — Catheter urine 은 voided 와 같이 취급 |
| Vaginal | cervical, vaginal, endometrial (GYN) |
| Cell block 부적합 | cell block |

분류 기준은 설정 ▸ *검체 분류* / *체크 칸별 분류* 에서 바꿀 수 있습니다. 검사코드가 없는 예전 QR 이나 코드표에 없는 코드는 예전처럼 모든 칸을 쓸 수 있습니다.

## 설치 / 실행 (Windows)

**가장 간단한 방법 — 파일 하나:** `amis_qr_saver.py` 만 복사한 뒤
`pip install pillow uiautomation` → `python amis_qr_saver.py` (콘솔 없이: `pythonw amis_qr_saver.py`).
(이 파일은 `python tools/make_single.py` 로 qrsaver 폴더에서 자동 생성됩니다)

**폴더 전체로 실행:**

1. [Python 3.8 이상](https://www.python.org/downloads/) 설치 (설치 시 *Add Python to PATH* 체크)
2. 이 폴더에서 `pip install -r requirements.txt` (미리보기용 Pillow)
3. `run.pyw` 더블클릭

Python 이 없는 PC에서 쓰려면 `build.bat` 을 실행해 `dist\AMIS_QR_Saver.exe` 를 만들어 복사하면 됩니다.

> AMIS 를 **관리자 권한**으로 실행하고 있다면 이 프로그램도 관리자 권한으로 실행해야 키 입력이 전달됩니다.

## 처음 한 번: 검사번호 입력창 지정 (AutomationId)

좌표 대신 **UI Automation 의 AutomationId** 로 병리결과입력[VSPSSPR059S] 화면의 검사번호 입력창을 직접 찾습니다.
창 위치·크기·해상도가 바뀌어도 정확하고, 입력된 값을 다시 읽어서 확인합니다.

1. AMIS 에서 **병리결과입력[VSPSSPR059S]** 화면을 엽니다.
2. 프로그램 **설정 → UI 요소 찾기** 를 누르고, 5초 안에 마우스를 평소 QR 을 태그하는 **검사번호 입력창** 위에 올려 둡니다.
3. 결과 창에 입력창의 AutomationId 와 상위 요소(화면) 정보가 표시되고 **자동 저장**됩니다.
   - AutomationId 가 비어 있으면, 결과 창의 *화면 안의 입력칸 목록* 에서 검사번호 값이 들어 있는 칸의 ID 를 *검사번호 입력창 ID* 에 직접 입력하세요.
4. **찾기 테스트** 로 입력창과 `Negative for malignant cells` 항목이 잡히는지 확인합니다.

처리 순서: 화면(VSPSSPR059S) 찾기 → 검사번호 입력창(AutomationId) 에 값 설정 → 값 확인 → 조회 대기
→ **화면에 그 검사번호가 조회됐는지 확인** → **Negative for malignant cells 가 선택돼 있는지 확인** → F9(저장).

- Enter 는 보내지 않습니다(입력만으로 조회됨). 필요하면 설정의 *입력 후 Enter 전송* 을 켜세요.
- 조회 확인: 입력창이 아닌 다른 곳(병리번호 칸, 목록 등)에 같은 검사번호가 보여야 F9 를 누릅니다.
  조회가 안 된 채 F9 를 누르면 화면에 남아 있던 **이전 검사가 다시 저장**될 수 있기 때문입니다.
  `화면에 … 가 조회되지 않아 저장하지 않았습니다` 로 실패하면 *입력 후 Enter 전송* 을 켜 보세요.
기본값이 선택돼 있지 않거나 찾을 수 없으면 저장하지 않고 `저장실패` 로 표시합니다(설정에서 끌 수 있음).

입력창이 일반 Windows 컨트롤이면 Enter/F9 를 메시지로 보내므로 **AMIS 를 앞으로 띄우지 않고 백그라운드로** 진행됩니다.
그렇지 않으면 사용자가 쉬는 동안 잠깐 AMIS 로 전환해서 처리합니다.

> UI 자동화가 안 되는 화면이면 *좌표 방식 (보조)* 의 **위치 지정** 으로 예전 방식도 쓸 수 있습니다.

## 사용 방법

1. **QR 태그** 칸에 커서가 있는 상태에서 검사의뢰서 QR 을 차례로 태그 → 목록에 `대기중` 으로 쌓입니다.
2. **▶ 시작** (또는 Action ▸ 자동저장 시작).
3. 그대로 다른 일을 해도 됩니다. 키보드/마우스를 쓰는 동안엔 멈춰 있다가, 손을 떼고 설정한 시간이 지나면 AMIS 로 전환해서 한 건 저장하고 **원래 쓰던 창으로 되돌아옵니다**.
4. `축소창 ▣` 으로 작은 창만 띄워 두고 진행 상황을 볼 수 있습니다.
5. 실패한 건은 비고에 사유가 남고, **실패항목 재시도** 로 다시 돌릴 수 있습니다.

## 설정 항목

| 항목 | 기본값 | 설명 |
|---|---|---|
| 창 제목 포함 글자 | `AMIS` | AMIS 창을 찾는 기준 |
| 화면 ID | `VSPSSPR059S` | 병리결과입력 화면 |
| 검사번호 입력창 ID | (UI 요소 찾기로 저장) | AutomationId |
| Enter / F9 전송 | 자동 | 가능하면 백그라운드(메시지), 아니면 키보드 |
| 입력 후 Enter 전송 | 꺼짐 | 입력만으로 조회되므로 보통 불필요 |
| F9 전 조회 결과 확인 | 켜짐 | 화면에 해당 검사번호가 조회됐을 때만 F9 |
| 저장 전 기본값 확인 | 켜짐 | `Negative for malignant cells` 선택 확인 후에만 F9 |
| 사용자 미사용 대기 | 5초 | 이 시간 동안 입력이 없을 때만 작업 |
| 조회 대기 / 저장 대기 | 2초 / 2초 | PC·네트워크가 느리면 늘려 주세요 |
| 검사번호 입력 방식 | UI 자동화 | 한/영 상태와 무관. 안 되면 **진단 / 입력 테스트** 로 되는 방식을 찾으세요 |
| 기존 내용 지우기 | Home → Shift+End | 칸에 남은 이전 번호 삭제 방법 |
| 저장 키 | F9 | Action ▸ 저장 [F9] 와 동일 |
| 확인/알림창 자동 처리 | 켜짐 | 조회·저장 후 뜨는 알림창을 Enter 로 닫음 |
| 실패 메시지 단어 | 실패,오류,… | 알림창 내용에 포함되면 `저장실패` 처리 |

## 입력이 안 될 때 (문제 해결)

**설정 → 진단 / 입력 테스트** (또는 Action ▸ 진단 / 입력 테스트) 를 눌러 주세요.
AMIS 창/권한/검사번호 칸 정보를 확인하고, 입력 방식 4가지를 실제로 넣어 본 뒤 **되는 방식을 자동으로 설정**합니다.
결과 창의 **복사** 버튼으로 내용을 복사해 전달하면 원인 파악이 빠릅니다.

| 원인 | 증상 | 해결 |
|---|---|---|
| AMIS 가 관리자 권한으로 실행 중 | 어떤 방식으로도 입력이 안 됨 (Windows 가 입력을 차단) | Action ▸ **관리자 권한으로 다시 실행** (시작 시 자동 안내) |
| 키보드 보안 프로그램 | 가상 키 입력만 막힘 | 입력 방식 **메시지 직접전송 (백그라운드)** |
| 붙여넣기 차단 | 붙여넣기만 실패 | 진단 결과에 따라 다른 방식 자동 선택 |

- **메시지 직접전송** 방식은 AMIS 를 앞으로 띄우지 않고 검사번호 칸에 값을 넣고 Enter/F9 메시지를 보내므로,
  다른 작업을 하는 중에도 화면 전환 없이 진행됩니다.
- 일반 입력칸이면 번호가 실제로 들어갔는지 읽어서 확인하고, 안 들어갔으면 F9 를 누르지 않고 `저장실패(검사번호가 입력되지 않았습니다)` 로 표시합니다.

## 동작 원리 / 참고

- AMIS 는 키 입력을 받으려면 화면 맨 앞에 있어야 하므로, 완전한 백그라운드 대신
  **"사용자가 쉬는 동안만 잠깐 AMIS 로 전환 → 저장 → 원래 창 복귀"** 방식으로 동작합니다.
  작업 중에 마우스/키보드를 건드리면 그 건은 즉시 중단되고 `대기중` 으로 돌아갑니다(F9 를 누르기 전이라면 저장되지 않음).
- `저장완료` 는 *F9 를 누른 뒤 실패 알림창이 뜨지 않았음* 을 의미합니다. 처음 사용할 때는 몇 건을 AMIS 에서 직접 확인해 주세요.
- 조회된 화면의 라디오 버튼(예: Negative for malignant cells) **기본값을 그대로 저장**하며, 프로그램이 값을 바꾸지 않습니다.

## 파일 구성

```
run.pyw              실행 파일
qrsaver/gui.py       화면 (AMIS 3.0 스타일 메인창, 축소창)
qrsaver/worker.py    자동 저장 작업 (유휴 감지, 입력, F9, 알림창 처리)
qrsaver/uia.py       UI Automation (AutomationId 로 입력창 찾기)
qrsaver/win32.py     Windows API (창 활성화, 키/마우스 입력, 화면 캡처)
qrsaver/models.py    QR 목록 / 상태 저장
qrsaver/hangul.py    스캔값 보정 (한글 자판 → 영문)
tests/               단위 테스트 (python -m unittest discover -s tests)
```
